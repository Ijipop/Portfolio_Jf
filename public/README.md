# Dossier public (Next.js)

Les fichiers placés ici sont servis à la racine du site.

**Pour afficher l’image Montréal dans la carte Localisation (page Contact) :**

1. Copiez votre fichier `montreal.png` dans ce dossier.
2. Chemin complet attendu : `Portfolio/public/montreal.png`
3. Redémarrez le serveur de dev (`npm run dev`) si besoin.

L’image sera alors disponible à l’URL `/montreal.png`.

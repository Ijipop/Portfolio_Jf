Timelendr – captures pour le carrousel du site

1. Copiez vos fichiers .png dans ce dossier (public/img/timelendr/).
2. Éditez gallery.json : liste des noms de fichiers, par ex.
   ["ecran-calendrier.png", "ecran-timeline.png"]

Ordre = ordre d’affichage dans le carrousel.

Légendes (1re image = galleryCap1, etc.) : fichier
app/i18n/translations.ts → clés timelendr.galleryCap1 … galleryCap8 (FR + EN).
